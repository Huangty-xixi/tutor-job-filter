# 家教单筛选器

把中介发在微信里的家教单，**整段粘进去**，自动按年级、科目、距离、时薪分类成「可投 / 差一条 / 不符合」。

单文件、零依赖、不联网，双击就能用。

> 缘起：在长沙找家教时，一天收到上百条单子，格式还各不一样（编号帖、`【编号】`、`b2126` 这种代号、纯文字）。用眼睛筛一遍要半小时，还容易漏掉近的、钱多的。

## 特性

- **一次几十条**：空行和单号自动切分，不用整理格式
- **单条复制**：每行右侧的「复制」，一键把这条家教单原文复制走，直接转给别人
- **历史粘贴**：粘过的整段自动存进本机（最多 20 条），点「载入」回到那次的内容，可单条删或一键清空
- **原文一字不改**：每条都保留原始整段，方便核对、转发
- **自动折算时薪**：`100-120/h`、`100元一小时`、`220/2h`、`400/天`、`100一次` 都能算成时薪
- **识别这些格式**：
  ```
  ACS26102301            【编号】2203          LLS2428
  b2126                  【家庭单】570302      WY长沙261024001O
  长沙102401             M1020                83102501长沙
  ```
  以及没有单号的自由文本
- **城市规则可换**：`CONFIG.city` 一处改完，别的城市直接能用
- **结果可导出**：勾选、复制含原文，或导出 CSV（Excel 直接打开不乱码）

## 使用

### 在线版

打开 https://huangty-xixi.github.io/tutor-job-filter/

### 本地版

下载 `index.html`，双击用浏览器打开即可。断网也能用。

1. 左边粘贴整段文字（粘贴即自动筛选）
2. 右边看结果：点一行展开原文，点表头排序，点「可投/差一条/不符合」只看那一类
3. 单条要转发：点那行右侧的「复制」
4. 整批要转发：点「复制能投的（含原文）」，或「导出 CSV」

## 判定规则

| 维度 | 硬条件（不满足直接 ❌） | 软条件（只提示，算 ⚠️） |
|---|---|---|
| 年级 | 不在勾选的年级范围内 | — |
| 科目 | 没有你勾选的科目 | — |
| 性别 | 写明「女老师 / 女优先」，而你只接男老师能接的 | — |
| 硬门槛 | 研究生、已毕业、大四、教资、专业限定、院校限定、信息费、**专职/全职** | 要丰富经验、要高考成绩、含化学/生物 |
| 距离 | 第 3 档（远）或第 4 档（外地）未勾选 | 第 2 档（中）未勾选；位置认不出 |
| 单价 | 低于底线 20 元以上（小学 10 元） | 低于底线但在容差内；没认出单价 |

默认口径：高一 + 初一 + 初二 + 小学，数学（含奥数）+ 物理，初高中 ≥90 元/h，小学 ≥60 元/h，岳麓区 + 线上，排除限女老师和硬门槛。

## 配置

打开 `index.html`，最上面是配置区：

```js
var CONFIG = {
  city: {
    name: '长沙',
    districts: [ [/岳麓/, '岳麓区', 1], ... ],   // 区名 → 距离档位
    places:    [ [/梅溪湖|大学城/, '岳麓区', 1], ... ], // 只写小区/地铁站时的兜底
    tiers:     { 1:'近', 2:'中', 3:'远', 4:'外地', 5:'线上' }
  },
  defaults: { grades: [...], subjects: [...], areas: [1,5], minPay: 90, primaryMin: 60, maleOnly: true, hardOnly: true },
  subjects: { '数学': ['数学','奥数'], ... }
};
```

**换城市**：把 `districts` 和 `places` 换成你城市的区和常见片区即可，档位按通勤时间自己定。距离档位只影响“远/近”的判断，不影响其他规则。

## 已知限制

- 只按文本规则解析，**格式千奇百怪时可能漏字段**；漏了会标「认不出」，不会瞎猜
- 同一单被不同渠道转发两次，会被当成两条
- 薪资写「面议」「老师报价」的，时薪算不出来，会标「没认出单价」
- 城市规则目前只内置长沙


## 隐私

- 纯前端，**没有任何网络请求**（可断网运行验证）
- 唯一会落盘的是**历史粘贴**：存在这台电脑浏览器的 `localStorage`（键名 `tutorHistory`），最多 20 条、总计上限约 40 万字，点「清空历史」即全部删除
- 除此之外不写 cookie、不写 IndexedDB，结果和筛选条件都只在内存里
- 不会抓取平台数据，也不代替你判断，最终以中介给的信息为准
